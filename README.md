# AJAYNXT Salon — 10 Photo-First Hero Styles

GitHub Pages-ready salon, spa, beauty clinic and bridal studio concept website.

## Hero correction

The hero is deliberately minimal:
- 70–80% visible photography
- one short eyebrow
- one headline
- one sentence
- maximum two calls to action
- no hero booking form
- no hero stats
- no large information card
- compact style controls only

## Included

- 10 genuinely different photo-first hero layouts
- realistic salon, bridal, spa and beauty-service photography
- hero style auto-change every 60 seconds
- independent automatic color change every 18 seconds
- independent automatic text change every 24 seconds
- Lock Color, Lock Text and Lock Font
- dark and light modes
- visible color, text and font libraries
- service categories and booking
- interactive before/after comparison
- bridal packages and trial enquiry
- skin and beauty consultation section
- specialist profiles
- pricing structure
- appointment booking through WhatsApp
- location and hours
- FAQs
- mobile sticky Call, WhatsApp, Services and Book actions
- SEO title, description, canonical, Open Graph and schema
- robots.txt and sitemap.xml
- CNAME for salon.ajaynxt.com

## Publish

Upload every file to the repository root.

GitHub Pages:
- Settings > Pages
- Deploy from a branch
- Branch: main
- Folder: /(root)

## GoDaddy DNS

- Type: CNAME
- Name: salon
- Value: ajaynxt.github.io
- TTL: 1 Hour

## Important

This is a portfolio concept. Replace prices, availability, specialist profiles, before/after photographs, qualifications, contact details and service claims with verified client information before commercial publication.

Photos load from Pexels URLs, so an internet connection is required for imagery.
